# Troubleshooting

- If PowerShell blocks npm scripts, invoke `npm.cmd`, `npx.cmd`, or use the provided setup script with `-ExecutionPolicy Bypass`.
- A disconnected media root is not deleted. Reconnect it and press **Reescanear biblioteca**.
- Missing ffprobe disables technical probing but does not prevent filename-based catalog indexing.
- Diagnostics never include secrets; paths are redacted unless the local technical report explicitly opts in.
