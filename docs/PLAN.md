# Implementation plan

1. Bootstrap the Windows/Tauri monorepo and reproducible toolchain.
2. Deliver the local SQLite library, incremental scanner, and typed IPC.
3. Deliver the real catalog UI, metadata fallbacks, search, lists, and heroes.
4. Integrate libmpv, progress, tracks, and non-destructive image profiles.
5. Harden diagnostics, backups, tests, and the NSIS installer.

Android, HTTP/WebSocket APIs, streaming, QR pairing, remux, and HLS are explicitly deferred.
